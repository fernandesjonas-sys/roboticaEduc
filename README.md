# roboticaEduc
Este programa compara a luminosidade captada por dois sensores LDR e movimenta um servomotor em direção à maior iluminação. Utiliza-se o Arduino MEGA para montagem do circuito e processamento de entrada e saída de dados.
Funcionalidades: Leitura e resposta à luminosidade durante todo.
Integrante: JONAS FERNANDES DA SILVA - Polo João Pessoa.
